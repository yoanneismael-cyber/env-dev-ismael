# Journal des choix

## 2026-11-11 - Installation de Node.js

- **Décision :** Installer Node.js avec le dépôt NodeSource et `apt`.
- **Autres possibilités :** Le paquet `nodejs` d'Ubuntu, le site officiel `nodejs.org`.
- **Raison :** NodeSource fournit la version LTS récente, et les commandes peuvent être documentées dans mon README pour être reproduites à l'identique.

## 2026-11-12 - Système pour le terminal

- **Décision :** Utiliser Ubuntu avec WSL sur Windows 11.
- **Autres possibilités :** PowerShell, Git Bash, une machine virtuelle.
- **Raison :** WSL offre un véritable environnement Linux sans quitter Windows, identique à celui utilisé dans le cours.

## 2026-11-13 - Hébergement du dépôt Git

- **Décision :** Publier notre dépôt local sur un dépôt distant GitHub.
- **Autres possibilités :** GitLab, Bitbucket.
- **Raison :** Nous souhaitons sauvegarder notre code en ligne et suivre tous les changements de nos fichiers.

## 2026-11-17 - Choix de l'éditeur

- **Décision :** Utiliser VS Code.
- **Autres possibilités :** Notepad++, Vim, Sublime Text.
- **Raison :** VS Code s'intègre nativement à WSL, dispose d'un terminal intégré et gère très bien le Markdown et Git.
